웹 기획서 코멘트 현황

불러오는 중…
기획서 계정으로 로그인하면 내 코멘트를 불러오고 👀 를 남길 수 있습니다. 토큰은 macOS 키체인에만 보관합니다.
✓ 결정 완료 — 내가 👀 를 붙인 코멘트·답글 미결 (다음 회의 안건) — 체크하고 [👀 확인 완료]를 누르면 기획서에 👀 를 붙인다 우선순위 상우선순위 중 리뷰에서 다룰 순서 — 각 코멘트의 [우선순위] 버튼으로 지정 − 보류 — 답변 불필요, 체크할 수 없음. [보류] 버튼으로 지정·해제 답변 완료 기획 답글 수신 — 체크박스와 별개 축이다
결정 상태는 기획서의 👀 반응으로 판정합니다. 내가 👀 를 붙인 코멘트(본문 또는 기획 답글)가 결정 완료입니다. 미결 코멘트를 체크하고 [👀 확인 완료]를 누르면 대시보드 서버가 기획서에 👀 를 붙입니다 — 기획 답글이 있으면 마지막 답글에, 없으면 내 코멘트 본문에 붙이고, 반응 API 가 토글이라 직전에 다시 읽어 이미 붙은 건은 건너뜁니다. 우선순위·보류는 기획서에 없는 표시라 이 컴퓨터의 개인 상태 폴더에만 저장됩니다. [📝 MD 내보내기]는 현재 상태를 체크리스트 md 로 설정한 폴더에 저장합니다.
